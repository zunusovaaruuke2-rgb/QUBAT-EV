# QUBAT EV — нативное Android-приложение

Новый проект на Kotlin и Jetpack Compose для всего Кыргызстана. Русский интерфейс, тёмно-зелёная палитра, Android 8.0+ (API 26), target/compile SDK 35. Старый `QUBAT_EV_GitHub_Upload.zip` сохранён только как историческая справка: его WebView/HTML-код не используется.

**Все 16 локаций вымышленные. Их координаты — условные точки возле центров городов, а не адреса зарядок. Статусы не поступают от оборудования. Не используйте демо-маршруты для поездки к реальной зарядке.**

## Возможности

- Главная: настоящая нативная карта мира с перемещением, масштабом двумя пальцами и кнопками +/−. Начальный обзор Кыргызстана; можно уйти в соседние страны и любой регион мира. Без ключа работает MapLibre Native + OpenFreeMap/OpenStreetMap; с разрешённым Google ключом используется Google Maps SDK. Нужен интернет. Кнопка обзора возвращает в Кыргызстан, местоположение — к пользователю.
- Станции: поиск только по названию станции; фильтры мощности и статуса. Локации расположены в 16 городах. Бишкек, Ош, Джалал-Абад, Каракол, Нарын, Талас, Баткен, Балыкчи, Токмок, Чолпон-Ата, Кара-Балта, Токтогул, Узген, Кызыл-Кия, Кочкор, Кара-Куль. Набор данных можно расширять без ограничения рамками Бишкека.
- 16 демонстрационных локаций во всех областях Кыргызстана, по 4 или 8 аппаратов (96 аппаратов, 192 разъёма). Каждый аппарат: 80 кВт, GB/T DC, 13,5 сом/кВт·ч. Метки показывают число аппаратов и сегменты состояний разъёмов. На карте и во второй вкладке «Список» — одинаковая сетка аппаратов, у каждого по два GB/T DC разъёма. Нажатие на разъём показывает его состояние; только свободный можно выбрать для симуляции. Данные вымышленные.
- Геопозиция: после разрешения обновляется через GPS и сеть только при открытом приложении. Свежая известная позиция используется сразу; старая не показывается. На карте — синяя точка. Кнопка позиции повторно центрирует карту с масштабом улиц (15,5); GPS может уточнить первое приблизительное положение. При выключенном GPS или отказе показана ссылка на настройки. Каталог сортируется по расстоянию по прямой.
- Маршруты передаются во внешние 2ГИС или Google Maps после предупреждения о вымышленной точке. Встроенных платных Routing API нет. Дорожное покрытие, ограничения и ETA определяет навигатор.
- Зарядка: запуск/остановка, кВт·ч, время, стоимость; нельзя запустить недоступную станцию или второй параллельный сеанс. При исчерпании учебного баланса сеанс завершается, переплаты нет.
- Кошелёк: начальные 1500 учебных сомов, бесплатное учебное пополнение на 500, локальная история последних 100 операций. Во время сеанса пополнение блокируется.
- Профиль, описание демо-режима и использования данных. Нет авторизации, реальных платежей и EEJANN API.

## Сборка

Требуются JDK 17 или 21, Android SDK Platform 35 и доступ к Google Maven/Maven Central/Gradle distributions.

```sh
# Создайте local.properties со строкой sdk.dir=/путь/к/android-sdk
./gradlew assembleDebug testDebugUnitTest lintDebug
# Windows
# gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
Это debug APK, не production-подпись. Секреты/keystore не включены в репозиторий.

## Карты и лицензии

Приоритет 2ГИС изучен: [исследование и ограничения покрытия](docs/MAPS_RESEARCH.md). Рабочий SDK 2ГИС требует `dgissdk.key` и разрешённого доступа к API по подписке. Ключ в задаче не предоставлен; подписки не покупались и договоры не принимались. MapGL Android на WebView не используется.

Разрешённый резерв Google реализован через **Google Maps SDK for Android + Maps Compose**. В версии 1.1 без Google ключа автоматически используется **MapLibre Native + OpenFreeMap**, без регистрации/оплаты, вместо статичной схемы. Чтобы активировать именно Google Maps, владелец должен сам предоставить разрешённый ключ с Maps SDK for Android и включённым биллингом. Оставьте ключ пустым для карты OpenFreeMap без платного API-ключа. Карта получает тайлы по интернету; каталог, баланс и симуляция остаются локальными.

```sh
./gradlew assembleDebug -PMAPS_API_KEY=YOUR_RESTRICTED_ANDROID_KEY
# или переменная окружения MAPS_API_KEY; не коммитьте значение
```

Ограничьте ключ по Android package `kg.qubat.ev`, SHA-1 сертификата и только Maps SDK for Android. SHA-1: `./gradlew signingReport`. Android-ключ попадает в APK и не является серверным секретом: ограничения обязательны. Установите квоты и уведомления в аккаунте владельца. Никаких аккаунтов/покупок автоматически не создаётся. Для Google Maps нужны сеть и совместимые Google Play services. Без валидного ключа или при отсутствии покрытия сервисом карта не гарантируется; каталог и симуляция работают автономно.

## Архитектура и хранение

`Domain.kt` — независимые модели, каталог, поиск, расстояния, расчёт энергии и денег (денежные суммы в тыйынах). `ChargingViewModel.kt` — единый StateFlow, таймер, локальный snapshot SharedPreferences/JSON. `MainActivity.kt` — Compose-разделы и события. `CountryMap.kt` — переключение Google/MapLibre; `WorldMap.kt` — нативная карта мира и маркеры 4/8; `MapHome.kt` — компактные кнопки и карточка. Никаких WebView.

Сеанс сохраняет стартовое время и бюджет, восстанавливается после пересоздания/перезапуска, пересчитывается при открытии. Реальное оборудование в фоне не управляется: это модель прошедшего времени без foreground service. Системные часы влияют на симуляцию; для реального биллинга нужен серверный источник и идемпотентный протокол. Данные остаются локально, backup отключён. Удаление данных приложения сбрасывает кошелёк. При повреждённом snapshot создаётся новый учебный кошелёк.

## Проверки и CI

`./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` — расчёты тарифа/лимита, поиск/фильтры/геодезия, Android Lint, сборки приложения и UI-тестов.
`./gradlew connectedDebugAndroidTest` — smoke-тест навигации на устройстве/эмуляторе.
GitHub Actions собирает APK, выполняет unit-тесты/lint, сохраняет APK и отчёты; отдельная задача запускает Compose smoke-тест на эмуляторе API 35. Сборка CI по умолчанию без ключей и платежей.

См. [сценарии ручной приёмки](docs/ACCEPTANCE.md). Изменения вносятся отдельной веткой и PR; merge в main выполняется только владельцем после подтверждения.

## Карта мира без ключа · версия 1.1

[OpenFreeMap](https://openfreemap.org/) предоставляет публичную карту без API-ключа и регистрации. [Нативное подключение](https://openfreemap.org/quick_start/) использует стиль `https://tiles.openfreemap.org/styles/liberty`. На карте сохранена атрибуция OpenStreetMap/OpenMapTiles/OpenFreeMap; доступна ссылка на источник. Офлайн-загрузка регионов и массовая предзагрузка не реализованы, используются обычные запросы текущего экрана и стандартный кэш SDK. Картографический провайдер видит IP и запросы тайлов выбранной области; координаты зарядок — отдельные вымышленные данные QUBAT. Сервис не предоставляет SLA; если нет интернета, приложение сообщает о загрузке карты, а каталог/симуляция работают. Покупок и подписок нет.

## Аппараты и разъёмы · версия 1.2

Иерархия: 16 локаций → 96 аппаратов (по 4/8) → 192 разъёма (по два на аппарат). Цвета общие для схемы и карты: зелёный — свободен, красный — заряжается, жёлтый — завершён или ошибка, синий — подключён/ожидает старта, серый — недоступен. Завершение обозначено галочкой, ошибка — предупреждением; при нажатии видна отдельная текстовая подпись. Проценты в красных демо-разъёмах — явно учебные данные, не телеметрия оборудования.

Симуляция привязана к конкретному свободному разъёму. Во время своего сеанса он красный, после остановки жёлтый; действие «Освободить» возвращает зелёный. Состояние своего завершённого разъёма сохраняется локально вместе с кошельком, остальные демонстрационные разъёмы не меняются. Синие, занятые, ошибочные и недоступные разъёмы нельзя запустить.

### Версия 1.3

Дневная и ночная темы интерфейса и карты переключаются кнопкой солнца/луны; выбор сохраняется на устройстве. Иконка приложения и логотип заменены изображением Q, предоставленным пользователем. Номера разъёмов 1/2 показаны в контрастных кружках. На экране зарядки есть выбор аппарата и разъёма, процент батареи, компактные показатели и график мощности по проценту. График отражает только прошедшую часть демо-сеанса (постоянные 80 кВт, модель батареи 60 кВт·ч с началом 20%); ползунок показывает мощность при выбранном достигнутом проценте. Реальной телеметрии нет.

### Версия 1.4

Компактная кнопка поиска раскрывает поле названия станции на карте и в списке. Поиск не использует город или тип разъёма. Удалены выбор страны/города, заголовок и счётчик локаций над списком, а также легенда цветов. Цветные статусы самих разъёмов сохранены. Геопозиция обновляется в foreground, с повторным центрированием и приближением по кнопке.
