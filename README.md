# QUBAT EV — нативное Android-приложение

Новый проект на Kotlin и Jetpack Compose для всего Кыргызстана. Русский интерфейс, тёмно-зелёная палитра, Android 8.0+ (API 26), target/compile SDK 35. Старый `QUBAT_EV_GitHub_Upload.zip` сохранён только как историческая справка: его WebView/HTML-код не используется.

**Все четыре станции вымышленные. Их координаты — условные точки возле центров городов, а не адреса зарядок. Статусы не поступают от оборудования. Не используйте демо-маршруты для поездки к реальной зарядке.**

## Возможности

- Главная: обзор Кыргызстана, карта Google Maps при наличии ключа, честно обозначенная условная схема без ключа; выбор демо-станции.
- Станции: поиск по городу, названию и разъёму; фильтры мощности и статуса; выбор 14 городов. Бишкек, Ош, Джалал-Абад, Каракол, Нарын, Талас, Баткен, Балыкчи, Токмок, Чолпон-Ата, Кара-Балта, Токтогул, Узген, Кызыл-Кия. Набор данных можно расширять без ограничения рамками Бишкека.
- Ровно 4 демонстрационные станции (Бишкек/Ош/Джалал-Абад/Каракол), каждая 80 кВт, GB/T DC, 13,5 сом/кВт·ч. Две свободные, одна занята, одна недоступна. В остальных городах честное пустое состояние.
- Геопозиция только по кнопке: запрашиваются runtime permissions, допускается приблизительная позиция, есть обработка отказа/выключенного GPS/таймаута. Ближайшие точки определяются по геодезическому расстоянию **по прямой**, не по дороге. Каталог сортируется по расстоянию, главная показывает ближайшую точку и её статус.
- Маршруты передаются во внешние 2ГИС или Google Maps после предупреждения о вымышленной точке. Встроенных платных Routing API нет. Дорожное покрытие, ограничения и ETA определяет навигатор.
- Зарядка: запуск/остановка, кВт·ч, время, стоимость; нельзя запустить недоступную станцию или второй параллельный сеанс. При исчерпании учебного баланса сеанс завершается, переплаты нет.
- Кошелёк: начальные 1500 учебных сомов, бесплатное учебное пополнение на 500, локальная история последних 100 операций. Во время сеанса пополнение блокируется.
- Профиль, описание демо-режима и использования данных. Нет авторизации, реальных платежей и EEJANN API.

## Сборка

Требуются JDK 17 или 21, Android SDK Platform 35 и доступ к Google Maven/Maven Central/Gradle distributions.

```sh
# Создайте local.properties со строкой sdk.dir=/путь/к/android-sdk
./gradlew assembleDebug testDebugUnitTest lintDebug
# Windows
# gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
Это debug APK, не production-подпись. Секреты/keystore не включены в репозиторий.

## Карты и лицензии

Приоритет 2ГИС изучен: [исследование и ограничения покрытия](docs/MAPS_RESEARCH.md). Рабочий SDK 2ГИС требует `dgissdk.key` и разрешённого доступа к API по подписке. Ключ в задаче не предоставлен; подписки не покупались и договоры не принимались. MapGL Android на WebView не используется.

Разрешённый резерв реализован через **Google Maps SDK for Android + Maps Compose**. Чтобы активировать настоящую карту, владелец должен сам предоставить разрешённый ключ с Maps SDK for Android и включённым биллингом. Оставьте ключ пустым для бесплатного локального демо без запросов к картам.

```sh
./gradlew assembleDebug -PMAPS_API_KEY=YOUR_RESTRICTED_ANDROID_KEY
# или переменная окружения MAPS_API_KEY; не коммитьте значение
```

Ограничьте ключ по Android package `kg.qubat.ev`, SHA-1 сертификата и только Maps SDK for Android. SHA-1: `./gradlew signingReport`. Android-ключ попадает в APK и не является серверным секретом: ограничения обязательны. Установите квоты и уведомления в аккаунте владельца. Никаких аккаунтов/покупок автоматически не создаётся. Для Google Maps нужны сеть и совместимые Google Play services. Без валидного ключа или при отсутствии покрытия сервисом карта не гарантируется; каталог и симуляция работают автономно.

## Архитектура и хранение

`Domain.kt` — независимые модели, каталог, поиск, расстояния, расчёт энергии и денег (денежные суммы в тыйынах). `ChargingViewModel.kt` — единый StateFlow, таймер, локальный snapshot SharedPreferences/JSON. `MainActivity.kt` — Compose-разделы и события. `CountryMap.kt` — карта и схема. Никаких WebView.

Сеанс сохраняет стартовое время и бюджет, восстанавливается после пересоздания/перезапуска, пересчитывается при открытии. Реальное оборудование в фоне не управляется: это модель прошедшего времени без foreground service. Системные часы влияют на симуляцию; для реального биллинга нужен серверный источник и идемпотентный протокол. Данные остаются локально, backup отключён. Удаление данных приложения сбрасывает кошелёк. При повреждённом snapshot создаётся новый учебный кошелёк.

## Проверки и CI

`./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest` — расчёты тарифа/лимита, поиск/фильтры/геодезия, Android Lint, сборки приложения и UI-тестов.
`./gradlew connectedDebugAndroidTest` — smoke-тест навигации на устройстве/эмуляторе.
GitHub Actions собирает APK, выполняет unit-тесты/lint, сохраняет APK и отчёты; отдельная задача запускает Compose smoke-тест на эмуляторе API 35. Сборка CI по умолчанию без ключей и платежей.

См. [сценарии ручной приёмки](docs/ACCEPTANCE.md). Изменения вносятся отдельной веткой и PR; merge в main выполняется только владельцем после подтверждения.
