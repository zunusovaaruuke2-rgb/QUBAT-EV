# Android 1.13.0-demo (28)

Вместо увеличения шрифта по высоте телефона используются средние размеры: заголовки 16–17 sp, подписи 11–12 sp, значения показателей 14–15 sp. В сведениях двух автомобилей круг ограничен меньшей из ширины и высоты своей колонки и дополнительно 104 dp. Он не может расшириться по высоте за пределы колонки и зайти на показатели. У одного автомобиля круг ограничен 164 dp, показатели получили больше ширины. Энергия показана с двумя знаками после запятой; единица измерения сохраняется.

Подробности при двух сеансах имеют короткий заголовок «Зарядка» и отдельную кнопку назад. Проценты графика имеют колонку 42 dp и одну строку. Временных подписей три, в формате минуты:секунды (или часы:минуты для длинного интервала). Это исключает разрыв «100%» на две строки и пересечение времён.

В демо-данных только аппараты с одним или двумя разъёмами. Эти данные общие для выбора зарядки, списка и карты. Сохранённый сеанс на разъёме, удалённом этим обновлением, завершается ровно один раз: рассчитанная стоимость попадает в историю, баланс учитывает её, второй автомобиль продолжает работать. Неизвестные ID по-прежнему не заменяются другим портом.

Дополнительный UI-тест запускает телефон 360×800 с системным масштабом шрифта 1,2: проверяет непересечение круга/показателей, отсутствие обрезанных значений, одну строку процентов/времён и обе доступные остановки. Настройки тестового дисплея восстанавливаются после проверки. Старые проверки малой высоты, ролей кабинета, кошелька, миграции и независимой остановки сохранены. Новые изображения и разрешения на публикацию не нужны: значок остаётся из версии 1.12.
