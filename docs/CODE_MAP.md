# Где менять QUBAT EV

Исходники Android: `app/src/main/java/kg/qubat/ev/`.
Один раздел интерфейса находится в своей папке. Для визуального изменения
начинайте с файла нужного экрана; общие стили меняйте только при общей задаче.

## Порядок точечного изменения

1. Найдите раздел в таблице, откройте его файл. Для выбора зарядки достаточно
   `ChargeSelection.kt`; для графика — `ChargePercentChart.kt`.
2. Сохраните параметры экрана и его обработчики. Экран получает данные снаружи,
   поэтому изменение карточки не требует менять баланс, сохранения или расчёты.
3. Не копируйте общие цвета, кнопки, переводы и календарь в отдельные экраны.
   Компоненты всего приложения живут в `shared/`, компоненты одной функции —
   внутри её папки. Общие изменения проверяйте во всех местах использования.
4. После правки запускайте подходящие проверки. Перед выдачей APK:
   `./gradlew testDebugUnitTest lintDebug assembleRelease assembleDebugAndroidTest`,
   затем `./gradlew connectedDebugAndroidTest` на Android-эмуляторе.

Папки задают границы ответственности, но остаются в одном Gradle-модуле `app`
и пространстве имён `kg.qubat.ev`. Это сохраняет Android entry point, тесты,
сохранённые данные и импорты без дополнительного слоя навигации или зависимостей.
Такое разделение само по себе не добавляет фоновых задач, памяти или задержек.

## Выбор зарядки 1.15

Карточки аппаратов имеют одинаковую ширину и высоту. Рисунок, номер, мощность и
статус находятся на отдельных строках. На обычном телефоне видны четыре карточки;
дополнительные аппараты доступны горизонтальным движением. Крупный системный
шрифт уменьшает число одновременно видимых карточек, сохраняя место для текста.
В аппаратах остаются только один или два разъёма.

Ниже расположены разъёмы и сводка выбранного аппарата/разъёма. Статусы отражают
демо-данные: выбор свободного порта не выдаётся за физическое подключение машины.
Занятый или недоступный порт не разрешает старт. Кнопка запуска закреплена снизу;
на коротком экране или при крупном шрифте содержимое выбора можно прокрутить.
Активные зарядки по-прежнему помещаются на один экран.
