# Актуализация: карта мира в версии 1.1

По новому требованию карта перемещается по всему миру и масштабируется. Поскольку ключей 2ГИС/Google нет, статичная схема заменена на нативный MapLibre Android SDK 11.11.0 с публичным стилем OpenFreeMap Liberty. Это дополнительный бесплатный резерв для демо-сборки; Google Maps остаётся вариантом при переданном ключе.

Официальные источники: [MapLibre Native Android](https://maplibre.org/maplibre-native/android/examples/getting-started/), [OpenFreeMap](https://openfreemap.org/), [мобильное подключение](https://openfreemap.org/quick_start/). Публичный сервис не требует ключа/регистрации и разрешает коммерческое использование; атрибуция обязательна и сохранена. Платные планы не подключались. Офлайн-пакетов/предзагрузки нет. Для реальных тайлов нужен интернет; нет обещания одинаковой детализации каждого участка мира или SLA сервиса.

В каталоге теперь 16 вымышленных локаций по Кыргызстану, 96 зарядных мест по 80 кВт. За пределами Кыргызстана доступна базовая карта, но реальные или вымышленные зарубежные станции не добавлялись.

# Карты QUBAT EV: проверка на 1 ноября 2026

## Решение для этой сборки

Предпочтительный провайдер — официальный нативный 2GIS Android SDK. Доступный в задаче лицензионный ключ отсутствует. По официальной инструкции для получения геоданных нужен ключ `dgissdk.key` активной подписки. Не покупаем подписку, не создаём аккаунт, не принимаем оферту от имени владельца. Поэтому в текущем APK реализован разрешённый резерв **Google Maps SDK**. Он тоже требует принадлежащего владельцу ключа и billing-enabled проекта. Ключа нет — показываем отдельно подписанную условную схему, без имитации настоящих карт и без запросов к Maps SDK. Это ограничение готовности карт, а не утверждение о технической недоступности 2ГИС в Кыргызстане.

## Официальный Android SDK 2ГИС

Источники: [обзор](https://docs.2gis.com/android/sdk/overview), [подключение](https://docs.2gis.com/android/sdk/start).

Нативный Android SDK доступен в версиях Map и Full: карта/маркеры/поиск в обеих, встроенная навигация и офлайн-данные — Full. Их нельзя подключать вместе. Репозиторий — `https://artifactory.2gis.dev/sdk-maven-release`, зависимости `ru.dgis.sdk:sdk-map` или `sdk-full`; для будущего подключения нужно выбрать фиксированную актуальную версию, согласовать набор API и ключ с владельцем. Через Compose можно размещать нативный MapView с корректным lifecycle.

Не следует подменять это [MapGL Android](https://github.com/2gis/MapGL-Android), который использует WebView. В текущем проекте его нет.

## Покрытие Кыргызстана

Официальные региональные страницы подтверждают присутствие 2ГИС в [Бишкеке](https://info.2gis.kg/bishkek/products/download) и [Оше](https://info.2gis.kg/osh/products/download). Официальный [ЦИК КР](https://shailoo.gov.kg/ru/news/7650/) описывает использование 2ГИС в Кыргызстане и перечисляет Ош, Жалал-Абад, Каракол, Нарын, Баткен, Талас в контексте участков дистанционного голосования. Это свидетельство присутствия сервиса, **не гарантия полного покрытия SDK/дорог** для этих городов и всех сельских районов.

В документации [2ГИС Про](https://docs.2gis.com/pro/data/overview) Кыргызстан включён в доступные территории с оговоркой о частичной доступности наборов. Это относится к данным Про и не является матрицей покрытия Android SDK. Публичной гарантии одинаковой детализации, офлайн-пакетов, поиска и маршрутов на всей территории Кыргызстана в изученных первичных источниках не найдено. API-проверки с рабочим SDK-ключом не выполнялись.

Перед производственным выбором запросить у 2ГИС подтверждение покрытия отдельно для карты, поиска, автомобильной маршрутизации и offline: Бишкек, Ош, Джалал-Абад, Каракол, Нарын, Талас, Баткен, региональные трассы и населённые пункты вне центров. Нужны практические проверки маршрутов Бишкек–Ош, Нарын–Каракол, Ош–Баткен и точек в каждой области. Сейчас заявляется **географический охват каталога приложения**, а не гарантированное покрытие провайдера или наличие зарядок.

## Лицензия и расходы

[Оферта API](https://law.2gis.ru/offer-license-agreement-webapi) включает mSDK как вспомогательный модуль доступа к лицензируемым продуктам. Открытая лицензия кода примеров не предоставляет права бесплатно использовать серверные карты и API. Набор API, лимиты, учёт запросов, возможность офлайн-работы, территория, атрибуция и применимость договора для владельца из Кыргызстана должны проверяться по согласованной подписке и действующей оферте перед акцептом. Точную стоимость без согласованного набора/объёма не утверждаем. Логотипы/атрибуция провайдера не должны скрываться.

Резерв Google: [ключ и ограничения](https://developers.google.com/maps/documentation/android-sdk/get-api-key), [использование и биллинг](https://developers.google.com/maps/documentation/android-sdk/usage-and-billing). Google требует проект с включённым биллингом и ключ, даже когда отдельные виды использования имеют бесплатные лимиты. Это не разрешение включить биллинг без подтверждения владельца. Сервисы Google не активировались. Их реальное покрытие/маршруты в горных/приграничных районах также нуждаются в проверке.

## Маршруты в демо

2ГИС и Google открываются внешним ACTION_VIEW по координатам. Для 2ГИС используется [официальный deep link](https://help.2gis.com/question/developers-launching-2gis-navigation-using-deeplink) `dgis://2gis.ru/routeSearch/rsType/car/to/lon,lat`; при отсутствии приложения предлагается отдельно выбрать Google Maps. Стоимость платных Routing API приложением не вызывается. Перед переходом пользователь видит, что станция вымышлена. Полноценного turn-by-turn внутри QUBAT пока нет. При отсутствии приложения может открыться внешний браузер; это не WebView и не основа QUBAT EV. Для перехода к 2ГИС после разрешённого доступа заменяется только реализация карты, общие модели/поиск/кошелёк от провайдера не зависят.
