# Android 1.9.1: очистка и производительность

База — проверенная Android 1.9.0 (`5d68f566f41caa10c738ba0f6614086f33d2968e`). До изменений создан Git bundle исходников в `work/backups/qubat-before-03-11-2026.bundle`; исходные настройки сборки скопированы рядом. Работа изолирована в ветке `feat/android-performance-cleanup`.

## Что изменено

- Удалены прежние `PartnerDemoRepository`, его модели и `PartnerExcel`. Поиск ссылок подтвердил: действующий интерфейс использует `NativePartnerRepository` и `NativePartnerExcel`; к старой реализации обращались только её собственные тесты. Общие роли, аккаунт, период, сортировка и страницы сохранены.
- Удалены тесты упразднённого репозитория и экспорта. Границы дат отдельно проверяет `PartnerPeriodTest`; проверки прав, финансов, нового XLSX и хранения остаются в тестах действующего кабинета.
- Удалён 31 неиспользуемый импорт и дублирующая кнопка источников карты в кабинете. Источники по-прежнему доступны непосредственно на карте.
- Границы периода вычисляются один раз на выборку. Поиск по станции не повторяет обход станций для каждой сессии. Завершённые сессии группируются по станции и месяцу один раз, счета и расходы — по месяцу.
- Ставка для каждой пары «станция/день» выбирается один раз для расчётной аренды и фиксированной доли. Порядок денежного округления и правила неизвестных значений сохранены.
- Права на финансовые поля проверяются для снимка отчёта, без повторного создания набора прав для каждой его строки. Проверки области доступа на публичных операциях остаются.
- Смена языка меняет подписи MapLibre без повторной загрузки стиля и тайлов. Смена темы продолжает загружать соответствующий стиль. Маркеры Google Maps пересоздают bitmap при изменении рисунка метки, а не при каждом изменении выбранного ID или процента заряда.
- Словари и регулярные выражения локализации создаются по требованию. Русский интерфейс не компилирует заранее все шаблоны переводов.

## Что сохранено

Пять разделов водителя, расширенный кабинет, локальные данные, права, тарифы, расчёты и Excel, три языка, темы, анимации нажатия, обе карты и GPS. Ресурсы иконки приложения не изменены. Подключения, платёжные настройки и боевое оборудование не затрагиваются. Сериализованные модели и схема приватного снимка остаются прежними.

## Проверка

Команда сборки: `./gradlew testDebugUnitTest lintDebug assembleRelease assembleDebugAndroidTest`. В CI дополнительно запускаются сценарии `NavigationTest`, `PartnerCabinetTest` и `scripts/smoke_optimized.py`: сохранение тарифа непосредственно в release-APK, полное завершение процесса, повторное открытие точки, пять экранов водителя и 60 прокруток.

Для сравнения расчётов локальный JVM-стенд использует фиксированные дату/часы, разные роли и все предустановленные периоды. Сравниваются SHA-256 итогов, месячных финансов и строк отчётов до/после изменений. Нагрузочный вариант содержит 40 875 сессий. Измерение JVM-времени не является измерением FPS или гарантией отсутствия задержек на любом телефоне; результаты зависят от устройства и загрузки.

Точные результаты сборки и прогонов приводятся в PR и GitHub Actions. Работа карты по-прежнему зависит от интернета и провайдера тайлов.
