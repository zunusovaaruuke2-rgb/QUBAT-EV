# Android 1.12.0-demo (27)

Укрупнены выбор аппарата/разъёма, показатели зарядки и подписи навигации. В показателях значок занимает отдельную колонку слева; текст начинается правее с зазором 6–10 dp. В подробностях одного сеанса подписи 12–14 sp, значения 16–20 sp, значки 18–24 dp. Размеры зависят от доступной высоты; большой телефон использует больше свободного места, а не увеличенную пустоту между слишком мелкими карточками.

Один/два активных сеанса помещаются без вертикальной прокрутки. При выборе аппарата на маленьком экране список выбора допускает прокрутку; кнопка старта всегда закреплена внизу. Сохранены четыре разъёма, два сеанса, общий баланс и график процента по времени.

Удалён 3D-разворот всей страницы (включая поверхность карты) за 280 мс. Вместо него короткое появление прозрачностью за 100 мс. Искусственная пауза действия сокращена с 240 до 100 мс. Восстановление сжатия ускорено. У каждой объёмной карточки убраны два дополнительных прохода рисования смещённой тени; остаются кэшированные заливка и контур.

Новая иконка — исходный 1001067588.jpg, разрешённый владельцем для публикации. Пиксели файла не перерисовываются; используется оригинальная квадратная композиция. У adaptive icon отступ 14%, поэтому знак занимает меньшую часть видимой иконки. Внутри приложения белое внешнее поле отсекается при отображении, без изменения JPEG. Предыдущий PNG удалён.

Проверки: расчётные unit tests; UI проверяет видимость значков/стоимости, зазор между значком и текстом, шрифт значения не меньше 16 sp, две независимые остановки, четыре разъёма и старые сохранения. Диагностика кадров готового APK сохраняется CI. Результат эмулятора не гарантирует частоту кадров на конкретном телефоне.
