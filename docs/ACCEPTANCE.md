# Ручная приёмка

1. Чистая установка без ключа с интернетом: настоящая карта MapLibre/OpenFreeMap, пять вкладок, русские тексты, компактная демо-пометка. При отсутствии сети — сообщение о загрузке, каталог и симуляция доступны.
2. Каталог: 16 локаций, 96 мест (по 4/8). Ош, Нарын, Талас, Баткен → по одной точке. Неизвестный город → пустое состояние. Поиск «Жалал-Абад» находит точку. ≥120 кВт → нет точек; сброс возвращает 16. Статусы сочетаются с мощностью/городом.
3. Геопозиция: разрешить приблизительную/точную — ближайшая на главной и сортировка каталога; отказ/выключенный GPS/таймаут — понятный текст, города остаются доступны. Фонового запроса разрешений нет.
4. Карточка точки: статус, 80 кВт, GB/T DC, 13,5 сом/кВт·ч; предупреждение о вымышленных координатах. Проверить переходы в оба внешних навигатора и отсутствие подходящего обработчика.
5. Свободная станция: начать; спустя 60 сек около 1,333 кВт·ч и 18 сом. Переходы по вкладкам, поворот, сворачивание и перезапуск не создают второй сеанс. Вернуться/остановить — списание один раз, история обновлена. Занятая/недоступная — запуск заблокирован.
6. Кошелёк: учебное пополнение +500, во время сеанса заблокировано, запись истории переживает перезапуск. Баланс не становится отрицательным при длительной симуляции. Реальных форм оплаты нет.
7. С разрешённым Google Maps ключом: начальный обзор Кыргызстана, 16 демо-маркеров, карточки по нажатию, выбранный город фокусирует камеру; при плохой сети отображается подсказка. Проверить устройства с Google Play services. Ключ/геопозиция в репозиторий не попадают.
8. Проверить экран 320dp, увеличенный шрифт, планшет, TalkBack и системные отступы Android 15. Не считать этот список протоколом выполненных ручных тестов: фактические результаты перечисляются отдельно в отчёте сборки.

9. Карта: +/− меняют масштаб, свайп перемещает карту, pinch увеличивает/уменьшает. Уйти в Казахстан, Узбекистан, затем в другую часть мира; карта не ограничена Кыргызстаном. Вернуться кнопкой обзора. Маркеры 4/8, цвета свободных/занятых/недоступных мест соответствуют карточке. Атрибуция провайдера видна.
