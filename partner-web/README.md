# QUBAT EV — Кабинет партнёра

Самостоятельное адаптивное веб-демо, версия 0.1.0. Приложение водителя Android не изменяется.

Запуск: `npm start`, затем открыть http://localhost:4173. Зависимости JavaScript не требуются.
Проверки: `npm test` и `npm run check`.

[Полная инструкция и настройки](docs/README.md) · [Архитектура API](docs/API.md) · [Контракт будущего сервера](docs/openapi.yaml) · [Дальнейшие этапы](docs/ROADMAP.md)

Демонстрационный снимок — 1 ноября 2026, 18:00 Asia/Bishkek. Аккаунты переключаются кнопкой профиля в углу панели. Все станции и операции вымышленные; изменения сохраняются только в этом браузере. Это модель ролей, а не серверная авторизация. Для будущих реальных данных сервер обязан проверять каждую организацию, станцию и операцию.

Веб-интерфейс: мониторинг, точки и параметры, версия тарифа, отчёты с Excel, расчётные и фактические финансы, роли/назначения/скидки, бренды, уведомления и аудит. Команды реальному оборудованию отсутствуют.
